API reference
=============

One page per module, generated from the docstrings. Lengths and wavelengths are in
nanometres throughout; images are rows × columns, with ``y`` the row index increasing
downwards and ``x`` the column index (see :doc:`../guide/conventions`).

The modules ``io.meta``, ``preprocessing``, ``uncertainty`` and ``vibration`` are
placeholders: they state their scope, but nothing is implemented in them yet.
